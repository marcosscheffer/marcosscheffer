## Featured projects

### [Estik](https://github.com/marcosscheffer/estik-project-v2)
IT management system with support tickets, real-time chat, computer inventory, stock and notifications.

- REST API built with Java 25 and Spring Boot, using a hexagonal architecture organized by modules
- Authentication with Spring Security and JWT, using access and refresh tokens and role-based access control
- Real-time chat and notifications with Server-Sent Events
- PostgreSQL with Flyway migrations, Swagger documentation and a full environment on Docker Compose

[See the API code](https://github.com/marcosscheffer/estik-java-api-v2)

### [SpellTrade Batch](https://github.com/marcosscheffer/SpellTrade-batch)
Spring Batch application that imports large volumes of Magic: The Gathering cards from Scryfall data into a PostgreSQL database.

- JSON streaming with Jackson, to process large files with low memory usage
- Chunk-oriented processing with retry, skip and execution monitoring

### [Clinic API](https://github.com/marcosscheffer/clinic-api)
REST API for managing doctors and patients, built with Spring Boot, MySQL and Flyway.

- Paginated listings, data validation and soft delete
