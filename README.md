## Projetos em destaque

### [Estik](https://github.com/marcosscheffer/estik-project-v2)
Sistema de gestão de TI com chamados, chat em tempo real, inventário de computadores, estoque e notificações.

- API REST em Java 25 e Spring Boot, com arquitetura hexagonal organizada por módulos
- Autenticação com Spring Security e JWT, usando access e refresh tokens e controle de acesso por perfil
- Chat e notificações em tempo real com Server-Sent Events
- PostgreSQL com migrations em Flyway, documentação com Swagger e ambiente completo em Docker Compose

[Ver o código da API](https://github.com/marcosscheffer/estik-java-api-v2)

### [SpellTrade Batch](https://github.com/marcosscheffer/SpellTrade-batch)
Aplicação em Spring Batch que importa grandes volumes de cartas de Magic: The Gathering, a partir de dados do Scryfall, para um banco PostgreSQL.

- Leitura de JSON por streaming com Jackson, para processar arquivos grandes com pouco uso de memória
- Processamento em chunks, com retry, skip e monitoramento da execução

### [Clinic API](https://github.com/marcosscheffer/clinic-api)
API REST para gerenciar médicos e pacientes, com Spring Boot, MySQL e Flyway.

- Listagens paginadas, validação de dados e exclusão lógica
